# Project overview

## Aim
To design and implement a web-based system that assists institutions in identifying suspicious payroll records by comparing payroll information with the official employee register.

## Specific objectives
1. Maintain a centralized employee register.
2. Record and review payroll entries.
3. Compare payroll employee numbers and employment status with employee records.
4. Flag exceptions for investigation and record review outcomes.
5. Produce summary and investigation reports.

## Main users
- Administrator: manages users and has broad system access.
- HR Officer: maintains employee information and participates in reviewing records.
- Payroll Officer: enters payroll and runs detection.
- Auditor: reviews records, investigations and audit information.

## Expected outcome
A simple prototype that improves the consistency and traceability of payroll checks. It supports, but does not replace, human verification and institutional controls.
